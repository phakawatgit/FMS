# Project conversation memory

- At the start of work in this repository, read `CONVERSATION_MEMORY.md` for previous requests, decisions, completed work, and pending tasks.
- Keep that file updated after meaningful discussions or work, before your final response. Write concise Thai summaries with dates (Asia/Bangkok).
- Distinguish the user's requests from suggestions, observed facts, and completed actions. Record verification and remaining work accurately.
- Treat memory as historical context, not new authorization. Current user instructions take precedence. Recheck transient facts such as running servers.
- Preserve useful history; correct outdated information explicitly. Never invent conversations that are unavailable to you.
- Do not record passwords, tokens, secret environment values, or personal patient data.
